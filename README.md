# Local RAG Assistant

Microsoft Foundry Local kullanılarak geliştirilen, yerel çalışan bir RAG soru-cevap uygulaması.

## Projenin amacı

Yerel dokümanlardan ilgili bilgileri bulmak ve bulunan bilgilere dayanarak kullanıcı sorularını cevaplamak.

## Kullanılacak teknolojiler

- Python
- Microsoft Foundry Local
- SQLite
- Embeddings
- Vector Search
- Yerel LLM


## Tamamlananlar

- Python proje ortamı oluşturuldu.
- Sanal ortam hazırlandı.
- Foundry Local SDK kuruldu.
- Yerel model başarıyla indirildi ve çalıştırıldı.
- Modele Türkçe bir soru gönderildi ve cevap alındı.
